# Proyecto EmpresaUNI

## 1. Descripción del proyecto

Este proyecto consiste en el diseño e implementación de una base de datos relacional para la empresa EmpresaUNI, utilizando Microsoft SQL Server.

El sistema permite organizar y administrar la información relacionada con los centros de trabajo, empleados y directivos.

## 2. Tecnologías utilizadas

- Microsoft SQL Server.
- SQL Server Management Studio (SSMS).
- Draw.io.
- GitHub.

## 3. Estructura de la base de datos

La base de datos EmpresaUNI está integrada por tres tablas principales:

- **CentrosTrabajo:** almacena la información de los centros de trabajo.
- **Empleados:** contiene los datos personales y laborales de los empleados.
- **Directivos:** almacena información específica de los empleados que desempeñan funciones directivas.

## 4. Diagramas

En la carpeta `Diagramas` se encuentran los modelos de la base de datos en formatos PDF y Draw.io.

## 5. Script SQL

En la carpeta `Base_Datos` se encuentra el archivo `EmpresaUNI.sql`, que contiene las instrucciones para crear la base de datos, sus tablas, relaciones y registros.
